Embedding Widget Test & Demo

Mode 1: Popup Widget (Toggle Button)

Ein floating Button unten rechts öffnet den Chat. Perfekt für Websites, die den Chat diskret anbieten möchten.

<script src="http://localhost:3000/widget.js" data-chat-name="your-chat-name" data-mode="popup" data-position="bottom-right" data-theme="blue"></script>
  • Minimierbar mit Toggle-Button
  • Unread-Badge für neue Nachrichten
  • Mobile-responsive (Fullscreen auf Mobile)
  • Positionierbar (bottom-right, bottom-left, top-right, top-left)

→ Schau unten rechts für den Live-Demo!

Mode 2: Inline Embed (Fixed iframe)

Der Chat wird als fester iframe in einen Container eingebettet. Ideal für dedizierte Chat-Seiten oder Bereiche.

<div id="chat-container"></div> <script src="http://localhost:3000/widget.js" data-chat-name="your-chat-name" data-mode="inline" data-container="chat-container" data-theme="blue"></script>
  • Immer sichtbar
  • Vollständige Kontrolle über Größe und Position
  • Perfekt für dedizierte Chat-Bereiche

⚙️ Konfigurationsoptionen

Attribut Beschreibung Standard
data-chat-name Name des Chats (erforderlich) -
data-mode Modus: "popup" oder "inline" popup
data-theme Farbschema: blue, green, purple, orange, pink blue
data-position Position (nur popup): bottom-right, bottom-left, top-right, top-left bottom-right
data-container Container-ID (nur inline) -

🔔 JavaScript Events API

Das Widget sendet Custom Events, die du abfangen kannst:

// Listen for chat events window.addEventListener('chatMessage', (event) => { console.log('New chat message:', event.detail); }); window.addEventListener('chatOpen', () => { console.log('Chat opened'); }); window.addEventListener('chatClose', () => { console.log('Chat closed'); });

🚀 Getting Started

So bindest du den Chat in deine Website ein:

  1. Erstelle einen Chat auf der Hauptseite
  2. Kopiere den generierten Embed-Code
  3. Füge ihn vor dem schließenden </body> Tag deiner Website ein
  4. Fertig! 🎉
